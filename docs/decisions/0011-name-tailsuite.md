# 0011: The name is tailsuite

Status: **accepted** (2026-10-24).

## Decision

- **The name is tailsuite**, written in lower case like headscale and
  tailsnitch. A suite: test, infra and deploy in one tool.
- **The CLI is `tailsuite`**; the repo is `bulkhead-labs/tailsuite`.
- **Always state independence**: "not affiliated with or endorsed by
  Tailscale Inc." ([TRADEMARK.md](../../TRADEMARK.md)).

## Evidence (checked 2026-10-24)

| Name | Collisions |
|---|---|
| tailsuite | One empty repo with the same name; no Homebrew formula |
| tailtest | 17 repos with the same name (the largest has 12 stars); "tail test" is a statistics term, so search results would be poor |
| tailinfra | None, but vague |

Tailscale's community page asks that projects using its mark not imply an
official affiliation, and says more guidance is coming. No published rule
covers "tail-" names, which the community uses widely.

## Given up

- **The name leans on Tailscale's mark.** Check with a lawyer before any
  paid edition.
- **It ties the name to Tailscale** if other mesh VPNs are supported later.
